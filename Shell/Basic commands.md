# Basic commands

Sizni FAANG kompaniyalaridan biriga suhbatga taklif qilishdi. Suhbat asosan Shell va Linux operatsion tizimiga doir amaliy vazifalardan iborat. Sizga turli xil vazifalar beriladi, ularni terminalda bajarib, so'ngra tekshirib ko'rishingiz kerak bo'ladi. **Siz buni qila olasiz!**

Birinchi topshiriq: 
>42.txt nomli fayl yarating.

```shell
touch 42.txt
```

Qoyilmaqom!
Siz ikkinchi topshiriqga o'tdingiz.
>Sizga matnlar.txt fayli berilgan, buni ls orqali tekshirib olishingiz mumkin. Fayl ichidagi ma'lumotlarni console'ga chiqaring.

```shell
cat matnlar.txt
```

Juda ajoyib! Siz allaqachon uchinchi topshiriqdasiz.

>Endi **loyihalar**, **rasmlar**, **xujjatlar** nomli 3 dona folder yarating.

```shell
mkdir loyihalar rasmlar xujjatlar
```

To'rtinchi topshiriq:

>Xujjatlar folderi ichida fayl.txt faylini yarating va unga "Salom dunyo" yozuvini kiriting.

```shell
echo "Salom dunyo" > Xujjatlar/fayl.txt
```

Beshinchi topshiriq:
>Xujjatlar folderini o'chirib tashlang

```shell
rm -rf Xujjatlar
```
