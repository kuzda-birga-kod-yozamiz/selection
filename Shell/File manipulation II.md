# File Manipulation II — Bosqichma-bosqich amaliy topshiriqlar

Siz hali ham FAANG kompaniyasining qiyin sinovlaridan muvaffaqiyatli o‘tib ketyapsiz. Navbat — fayllarni izlash va ko‘chirish bo‘yicha ko‘nikmalaringizni ko‘rsatishga keldi. Ehtiyot bo‘ling, e'tibor talab qilinadi!

Birinchi topshiriq:
>Sizga kitoblar.txt fayli beriladi. Bu fayldan ichida "linux" so‘zi qatnashgan barcha qatorni chiqaring.
```shell
grep "linux" kitoblar.txt
```

Yaxshi ishladingiz! Ikkinchi topshiriqqa o‘tamiz.
Ikkinchi topshiriq:
>Joriy papkadan boshlab, butun tizim bo‘ylab fayl.txt nomli faylni qidirib toping.
```shell
find . -name fayl.txt
```

Zo‘r! Endi uchinchi sinov.
Uchinchi topshiriq:
>Sizda matn.txt fayli bor. Uni nusxa.txt nomi bilan nusxasini yarating.
```shell
cp matn.txt nusxa.txt
```
Tabriklayman, oxirgi sinovga yetib keldingiz!
To‘rtinchi topshiriq:
>nusxa.txt faylini arxiv papkasiga ko‘chiring. (Faraz qilaylik, arxiv papkasi mavjud.)
```shell
mv nusxa.txt arxiv/
```

✅ Siz File Manipulation II bosqichini ham zo‘r bajardingiz!
